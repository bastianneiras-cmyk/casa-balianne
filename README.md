# Casa Balianne

App de gastos personal. El frontend vive aquí (GitHub Pages) y los datos en Google Sheets vía Apps Script.

- `config.js`: URL de la implementación de Apps Script (`/exec`).
- La clave de acceso no va en este repositorio: se ingresa una vez en cada dispositivo
  (planilla → menú **App Gastos → Ver clave de la app**).
